# セキュリティ

## 自分の環境でのみ起動する

Mock は自分の PC か、自分の管理下にある VPS でのみ起動してください。SaaS やマルチテナントのサービスとして提供しないでください。脆弱性が多発している状況を踏まえ、他人のデータを預かる形での提供は危険と判断しています。

このドキュメントのサイトは静的なページだけで、Mock は含みません。

## ネットワーク

Mock は既定で `127.0.0.1` にのみバインドします。インターネットに公開しないでください。VPS で起動したときのブラウザからのアクセス方法は、まだ決まっていません。

Mock は本物の Discord に接続せず、外部との通信も行いません。

## トークン

- トークンは `data/discord-mock-state.json` に保存され、画面の URL にも含まれます。
- `data/` はコミットせず、URL も共有しないでください。
- REST API、Gateway、`/api/mock` はトークンを検証し、一致しなければ拒否します。
- 本物の Bot のトークンは使いません。テストでは Mock のトークンに差し替わります。

## DM

DM の内容は、宛先のユーザーでログインしたときだけ閲覧できます。`/api/mock/state` と実行結果には含めません。
