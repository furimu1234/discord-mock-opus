# Mock の画面

`pnpm web` または `pnpm app` が表示する URL をブラウザで開きます。URL にはトークンが含まれるので、共有しないでください。

Discord と同じように、左からサーバー、チャンネル、チャット、右パネルが並びます。一番左のレールで画面を切り替えます。

## テスト画面

ダミーユーザーを選んでログインします。メッセージの送信、スラッシュコマンド、ボタンなどの操作は、ログイン中のユーザーとして実行します。

ボイスチャンネルは接続と切断ができます。音声の再生はまだ実装していません。

DM は、宛先のユーザーでログインしたときだけ見られます。

右パネルはメンバーの一覧とテストケースの一覧を切り替えられます。

## テストケース

プロジェクトごとにテストケースをカードで表示します。カードをクリックすると、そのテストを実行します。

- テストは開いているチャンネルで、ログイン中のユーザーとして実行します。
- `describe` はカテゴリーとして表示し、折り畳めます。
- `users` で別のユーザーを指定したテストは、カードに実行ユーザーを表示します。
- 別のプロジェクトのテストを実行すると、そのプロジェクトの Bot に接続を切り替えます。
- テストの区切りをチャンネルに表示します。区切りは画面だけのもので、Bot やテストには見えません。

## 実行結果

画面から実行したテストの結果を、実行ごとに一覧で確認できます。成功、失敗、エラーに加えて、テスト中に Bot が呼び出した REST API のリクエストとレスポンス、Bot へ配信した Gateway イベントを表示します。

DM の内容は伏せます。結果は Mock のメモリに保存し、直近 100 回まで残ります。Mock を再起動すると消えます。

## DB Studio

Bot が使っているインメモリ DB のテーブルと行を確認できます。実行結果からは、そのテストの終了時の DB を開けます。編集はできません。

## 管理画面

ダミーユーザー、チャンネル、ロール、サーバーを追加、変更します。追加したデータはテストコードから追加したものと同じように扱います。
