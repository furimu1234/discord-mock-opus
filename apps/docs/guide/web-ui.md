# Mock の画面

`pnpm web` または `pnpm app` が表示する URL をブラウザで開きます。URL にはトークンが含まれるので、共有しないでください。

Discord と同じように、左からサーバー、チャンネル、チャット、右パネルが並びます。一番左のレールで画面を切り替えます。

## テスト画面

ダミーユーザーを選んでログインします。メッセージの送信、スラッシュコマンド、ボタンなどの操作は、ログイン中のユーザーとして実行します。

チャンネル一覧の上のサーバー名をクリックすると、サーバー設定を開けます。サーバー名の変更と、ロールの作成、削除、権限の変更ができます。チャンネルの編集画面では、ロールごとに権限を拒否、設定なし、許可の 3 状態で設定できます。設定した権限は、インタラクションの `member.permissions` と、ログイン中のユーザーの画面に反映します。

チャンネルとメンバーを右クリックするとメニューを開けます。チャンネルの編集、ID のコピー、ログインの切り替え、Bot のユーザーコマンドの実行、音量の変更ができます。メンバーを左クリックするとプロフィールを開き、権限があればロールを付与、剥奪できます。

ボイスチャンネルは接続と切断ができます。Bot とログイン中のユーザーが同じチャンネルにいる間、Bot の音声が流れます。テストがユーザーを接続したときは、音声のブロックを解除するために画面を 1 回クリックしてください。

DM は、宛先のユーザーでログインしたときだけ見られます。

右パネルはメンバーの一覧とテストケースの一覧を切り替えられます。

## テストケース

プロジェクトごとにテストケースをカードで表示します。カードをクリックすると、そのテストを実行します。

- テストは開いているチャンネルで、ログイン中のユーザーとして実行します。
- `describe` はカテゴリーとして表示し、折り畳めます。
- `users` で別のユーザーを指定したテストは、カードに実行ユーザーを表示します。
- プロジェクトを選ぶと、そのプロジェクトのテストケースを表示し、Bot の接続も切り替えます。切り替えると Bot は起動し直すので、それまでの DB は空になります。
- テストの区切りをチャンネルに表示します。区切りは画面だけのもので、Bot やテストには見えません。

## 実行結果

画面から実行したテストの結果を、実行ごとに一覧で確認できます。成功、失敗、エラーに加えて、テスト中に Bot が呼び出した REST API のリクエストとレスポンス、Bot へ配信した Gateway イベントを表示します。

DM の内容は伏せます。結果は Mock のメモリに保存し、直近 100 回まで残ります。Mock を再起動すると消えます。

## DB Studio

Bot が使っているインメモリ DB のテーブルと行を確認できます。実行結果からは、そのテストの終了時の DB を開けます。編集はできません。

## 管理画面

ダミーユーザーとサーバーを追加、変更します。追加したデータはテストコードから追加したものと同じように扱います。

チャンネル、ロール、メンバーのロールはサーバー内で設定します。チャンネルの一覧を右クリックするとチャンネルとカテゴリーを作成でき、チャンネル、カテゴリー、スレッドを右クリックすると編集や削除ができます。サーバー名をクリックすると「サーバー設定」を選べます。入力欄の「+」で画像やファイルの添付と、投票の作成ができます。フォーラムとメディアの投稿にも添付できます。添付は Mock を起動したファイルと同じ場所の `media` フォルダーに保存され、Mock を起動し直すと消えます。サーバー設定では、プロフィール、エンゲージメント、絵文字、スタンプ、メンバー（キック、BAN）、ロール、招待、連携サービス、安全設定、監査ログ、BAN したユーザー、AutoMod を扱えます。「サーバーをリセット」はチャンネル、ロール、権限などを初期データと同じ状態に戻します。画面で作ったサーバー、チャンネル、ロール、ユーザーなどは Mock を起動し直しても残り、メッセージは起動のたびに消えます。チャンネルの設定では、概要と権限に加えて、招待の作成と管理、ウェブフックとフォロー中のチャンネルの管理ができます。ウェブフックの URL は Mock を指すので、`curl` や discord.js の `WebhookClient` から送信できます。ロールは「サーバー設定」の「ロール」で作成、変更し、メンバーへの付与は「メンバー」で行います。

Bot プロジェクトでは、Bot のフォルダーを登録して起動できます。

- ラベルとフォルダーの絶対パスを 1 行ずつ追加します。パスは「参照」からフォルダーを選んで入力できます。Windows では、ドライブと WSL のディストリビューション（`WSL: Ubuntu` など）から辿れます。フォルダーに `@dismock/test` をインストールしておく必要があります。登録はリセットや再起動では消えません。
- 「全起動」は登録したすべてのプロジェクトをテストの一覧に出し、先頭の Bot を接続します。行の「起動」はそのプロジェクトの Bot を接続します。接続中の行は押せません。Bot はこのボタンを押すまで起動しません。
- 行の「停止」は接続中の Bot だけを止めて、テストの一覧は残します。「全停止」は testClient ごと止めます。
- 行の削除は、ラベルの左の × で行います。testClient の起動中は削除できません。
- 登録したラベルは、テストケースのプロジェクトの一覧に表示されます。
- 起動するとフォルダーのコードが PC 上で実行されます。信頼できるフォルダーだけを追加してください。登録と起動は `127.0.0.1` で起動した Mock でのみ使えます。
