  - title: Discord そっくりの画面
    details: ブラウザでメッセージを見ながら、テストをカードから実行できます。
  - title: 実行結果と通信を確認
    details: テストごとの成功と失敗に加えて、Bot の REST API のリクエストと Gateway イベントを見られます。
  - title: Jest と同じ書き方
    details: describe、test、expect に加えて、ダミーユーザーとしてコマンドやボタンを操作できます。
  - title: インメモリ DB
    details: PostgreSQL、MySQL、SQLite、Google スプレッドシートを、接続コードのまま動かせます。
  - title: 自分の環境だけで動く
    details: Mock は自分の PC や VPS で起動し、既定で 127.0.0.1 にのみバインドします。
